# Search engine icons

Official website favicons and touch icons, initially downloaded on 2026-09-05.
Low-resolution icons replaced with original high-resolution PNGs on 2026-09-09.
Stored locally so Spotlight settings do not need network access to show logos.
The original image bytes and brand colors are preserved; file extensions follow
actual image formats (some sites serve PNG data from `.ico` URLs).
Raster assets are at least 96 × 96 pixels; no low-resolution images are upscaled.

These brand marks belong to their respective owners and retain their original
copyright and trademark terms. They identify the available search services;
no endorsement or project ownership of the marks is implied.
