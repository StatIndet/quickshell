# Cloud provider icons

The SVG assets in this directory are stored locally so the control center does
not require network access to render provider lists.

- Existing Google Drive, Microsoft OneDrive, and Cloudflare assets use the
  Iconify `logos` collection.
- Files prefixed `logos--` were downloaded from the colorful Iconify SVG Logos
  collection.
- Files prefixed `simple-icons--` were downloaded through the Iconify API from
  Simple Icons and rendered with the provider's brand color.
- Additional open-source Iconify collections (`arcticons`, `token-branded`, and
  `thesvg-color`) cover brands that are absent from SVG Logos and Simple Icons.

Sources were retrieved on 2026-08-29:

- https://github.com/iconify/icon-sets
- https://github.com/simple-icons/simple-icons
